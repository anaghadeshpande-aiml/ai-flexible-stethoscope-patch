# System Architecture

The system consists of a flexible stethoscope patch, signal processing unit, AI inference module, and cloud-based monitoring dashboard.

## Components
- Flexible MEMS acoustic sensor patch
- Microcontroller (ESP32 / ARM Cortex)
- Wireless communication module
- Mobile application
- Cloud server for data visualization

## Data Flow
1. Sound acquisition
2. Signal preprocessing
3. Feature extraction
4. AI-based classification
5. Real-time visualization
